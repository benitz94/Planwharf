# Planwharf quick start

1. **Sign in** to at least one AI coding tool: Codex, Claude Code, Grok CLI or Antigravity.
2. **Download** the native app for your system from the [latest release](https://github.com/benitz94/Planwharf/releases/latest) (`Planwharf-native-<system>-vX.Y.Z.zip`), extract it, and open `Planwharf`.
3. **Team** (top right): choose a lead, press **Build** on one model and **Verify** on another.
4. **+ New project**: a name and a folder.
5. Tell the lead what to build, in plain words. When it suggests a goal, press **Let the crew do it**.

Follow the work in the chat; **Stop the crew** stops it, **Resume** continues later. When it finishes, try the result in the project folder, then press **Push**: the branch goes to GitHub and the pull request opens. Nothing reaches `main` unless you merge it.

More: [first project guide](HOW-TO.md) · [the chat view](CHAT-VIEW.md) · [user guide](USER-GUIDE.md).
